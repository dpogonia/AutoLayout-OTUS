# AutoLayout

One screen for practicing Auto Layout. An OTUS study project.

The screen has two colored labels and a star. In portrait the labels sit in a row at the center, and the star sits about a tenth of the screen above the center, no closer than 10 points to a label. In landscape the three views sit in one row, with equal gaps and a 20-point inset from the edges. Turning the device swaps the constraint set.

## Stack

UIKit, Auto Layout.

## Run

```bash
git clone https://github.com/dpogonia/AutoLayout-OTUS.git
cd AutoLayout-OTUS
open AutolayoutOTUS.xcodeproj
```

Run the **AutolayoutOTUS** scheme on an iPhone simulator and rotate it.
