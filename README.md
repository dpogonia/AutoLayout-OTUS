# AutoLayout

Один экран для тренировки Auto Layout. Учебный проект OTUS.

На экране две цветные подписи и звезда. В портрете подписи стоят в ряд по центру, звезда выше центра примерно на десятую часть экрана и не ближе 10 пунктов к подписи. В ландшафте три элемента в один ряд, с равными промежутками и отступом 20 пунктов от краёв. При повороте набор констрейнтов меняется.

## Стек

UIKit, Auto Layout.

## Запуск

```bash
git clone https://github.com/dpogonia/AutoLayout-OTUS.git
cd AutoLayout-OTUS
open AutolayoutOTUS.xcodeproj
```

Запустите схему **AutolayoutOTUS** на симуляторе iPhone и поверните его.
